# Where the F is my cursor 
[![release](https://img.shields.io/github/v/release/Nechja/wherethefismycursor)](https://github.com/Nechja/wherethefismycursor/releases)

This is an app I built for a friend of mine who kept losing his cursor while gaming.

Grab the latest exe from [releases](https://github.com/Nechja/wherethefismycursor/releases), or from powershell:

```powershell
$dir = "$env:LOCALAPPDATA\wherethefismycursor"
mkdir $dir -Force | Out-Null
iwr https://github.com/Nechja/wherethefismycursor/releases/latest/download/wherethefismycursor.exe -OutFile "$dir\wherethefismycursor.exe"
& "$dir\wherethefismycursor.exe"
```
